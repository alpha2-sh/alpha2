# alpha2-geometry

Deterministic vector geometry and coverage rasterization for alpha2 shapes.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It turns a shapes generator's content tree into device-pixel paths, cuts them by length, strokes them, and rasterizes their coverage the same way, to the byte, on every target. Most programs use it through the [`alpha2`](https://crates.io/crates/alpha2) crate.
