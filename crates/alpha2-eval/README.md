# alpha2-eval

Pure alpha2 timeline evaluation.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is the timeline evaluation under `alpha2-engine`; most programs use the engine through the [`alpha2`](https://crates.io/crates/alpha2) crate.

- [Documentation](https://docs.rs/alpha2-eval)
- [Repository](https://github.com/alpha2-sh/alpha2)
