# alpha2-render

Render graph and effect registry for alpha2.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. Most programs use it through the [`alpha2`](https://crates.io/crates/alpha2) crate, which re-exports it as `alpha2::render`.

- [Documentation](https://docs.rs/alpha2-render)
- [Repository](https://github.com/alpha2-sh/alpha2)
