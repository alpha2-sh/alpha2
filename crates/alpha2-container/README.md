# alpha2-container

alpha2's own media container layer in pure Rust: MP4, MOV and M4A, Matroska and WebM, WAV, MP3,
ADTS, FLAC and Ogg demuxers, and MP4 and Matroska/WebM muxers, with edit lists, codec priming and
deterministic output. The mobile hosts demux and mux with it; desktop hosts use FFmpeg.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU.
