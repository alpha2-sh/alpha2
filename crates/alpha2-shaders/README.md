# alpha2-shaders

WGSL and WESL shader assets for alpha2.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It holds the shaders `alpha2-render` compiles; most programs use the engine through the [`alpha2`](https://crates.io/crates/alpha2) crate.

- [Documentation](https://docs.rs/alpha2-shaders)
- [Repository](https://github.com/alpha2-sh/alpha2)
