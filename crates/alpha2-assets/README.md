# alpha2-assets

Asset identity, proxy selection, and conform reports for alpha2 hosts.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. `alpha2-host` and the browser engine (`alpha2-wasm`) make their media identity, proxy and conform decisions with it.

- [Documentation](https://docs.rs/alpha2-assets)
- [Repository](https://github.com/alpha2-sh/alpha2)
