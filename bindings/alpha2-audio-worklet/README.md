# alpha2-audio-worklet

C-ABI wasm binding for the alpha2 AudioWorklet host.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is built into the AudioWorklet's WebAssembly module, which the npm package [`alpha2`](https://www.npmjs.com/package/alpha2) ships as `alpha2/wasm/alpha2_audio_worklet.wasm`.

- [Documentation](https://docs.rs/alpha2-audio-worklet)
- [Repository](https://github.com/alpha2-sh/alpha2)
