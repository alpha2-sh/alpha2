# alpha2-build-support

Build-script helpers, and the C headers their shims share, for the alpha2 crates that link FFmpeg.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is a build-dependency of the alpha2 crates that link FFmpeg: `alpha2-ffmpeg-bridge`, `alpha2-native-gpu`, [`alpha2-native`](https://crates.io/crates/alpha2-native) and `alpha2-host`.

- [Documentation](https://docs.rs/alpha2-build-support)
- [Repository](https://github.com/alpha2-sh/alpha2)
