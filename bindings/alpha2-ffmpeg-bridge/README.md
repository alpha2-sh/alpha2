# alpha2-ffmpeg-bridge

Small audited unsafe boundary for FFmpeg buffers used by alpha2-native.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is part of `alpha2-native`, `alpha2-native-gpu` and `alpha2-host`, which link FFmpeg 8.

- [Documentation](https://docs.rs/alpha2-ffmpeg-bridge)
- [Repository](https://github.com/alpha2-sh/alpha2)
