# alpha2-wasm

Shared web preview and export wasm binding for alpha2.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is built into the engine's WebAssembly module, which the npm package [`alpha2`](https://www.npmjs.com/package/alpha2) ships as `alpha2/wasm`.

- [Documentation](https://docs.rs/alpha2-wasm)
- [Repository](https://github.com/alpha2-sh/alpha2)
