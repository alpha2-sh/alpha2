# alpha2-text

Portable text shaping and rasterization for alpha2 hosts, native and wasm.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. `alpha2-engine` and the browser engine (`alpha2-wasm`) draw text with it, so preview and export draw the same text from the same fonts.

- [Documentation](https://docs.rs/alpha2-text)
- [Repository](https://github.com/alpha2-sh/alpha2)
