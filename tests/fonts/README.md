# alpha2 text fixtures

- `Alpha2Fixture.ttf` is an unmodified copy of DejaVu Sans 2.37: Latin, Hebrew, Arabic, combining marks, symbols. Text tests, the text golden (`tests/golden/text_raster.json`), and caption, SVG, and extension tests use it. DejaVu's permissive font license is reproduced in `LICENSE-DejaVu.txt`. To refresh it from a DejaVu 2.37 source tree, run `DEJAVU_SANS=/path/to/DejaVuSans.ttf BLACK_HAN_SANS=/path/to/BlackHanSans-Regular.ttf tests/corpus/generate/generate.sh fonts` (both fixture fonts).
- `Alpha2FixtureHangul.ttf` is a subset of Black Han Sans 1.001 to a few dozen Hangul syllables, renamed "Alpha2 Fixture Hangul". It has no Latin, digits, or space, so with the DejaVu fixture before it every mixed Korean and Latin line splits into runs of both fonts: the fallback tests in `bindings/alpha2-text` and the golden's mixed cases. Black Han Sans is under the SIL Open Font License 1.1 (`OFL-BlackHanSans.txt`) and reserves no font name. Regenerate it with the same command (`tests/corpus/generate/font-hangul.sh`, fontTools); the output is the same bytes each run.

- `Alpha2FixtureEmojiColr.ttf` and `Alpha2FixtureEmojiBitmap.ttf` are Noto Color Emoji 2.051 in its COLRv1 and its CBDT builds, subset to a face, an eye with U+FE0F, a heart, a thumbs up with a skin tone, a family joined by ZWJ, Korea's flag, and keycap one, with the ligatures that join the sequences, and renamed "Alpha2 Fixture Emoji Colr" and "Alpha2 Fixture Emoji Bitmap". The color tests in `bindings/alpha2-text` and the golden's emoji cases draw them. Noto Color Emoji is under the SIL Open Font License 1.1 (`OFL-NotoEmoji.txt`) and reserves no font name. Regenerate them with `NOTO_EMOJI_COLRV1=/path/to/Noto-COLRv1.ttf NOTO_EMOJI_CBDT=/path/to/NotoColorEmoji.ttf tests/corpus/generate/generate.sh emoji-fonts` (`font-emoji.sh`, fontTools), from the `fonts/` directory of the noto-emoji `v2.051` tag.
- `Alpha2FixtureColor.ttf` is drawn from scratch by `tests/corpus/generate/font-color.py` (run by the same step): COLR glyphs at U+E000 to U+E005 for version 0 layers with the text's color, a linear, a radial, and a sweep gradient, a composite, and a transform under a clip box. Both steps write the same bytes each run.

The portable host draws color glyphs in color under `emojiPolicy` `color` (the default) and an emoji tries the color fonts first; `monochrome` draws every glyph's outline, if it has one, and `replace` draws one U+FFFD per emoji grapheme. Checksums are in `MANIFEST.md`.
