# alpha2-extensions-web

The extension providers as their own wasm module, loaded by a page only when it opens such a source.

Part of [alpha2](https://github.com/alpha2-sh/alpha2), a media engine that renders timeline projects on the GPU. It is built into the WebAssembly module the npm package [`alpha2`](https://www.npmjs.com/package/alpha2) ships as `alpha2/extensions-wasm`.

- [Documentation](https://docs.rs/alpha2-extensions-web)
- [Repository](https://github.com/alpha2-sh/alpha2)
